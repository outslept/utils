# utils

A curated collection of TypeScript utilities for modern development. Copy what you need.

Inspired by antfu/utils, but is somewhat personal.

## Structure

```
is/           # Type checking
guards/       # Advanced validation
array/        # Array utilities
object/       # Object utilities
string/       # String formatting
async/        # Async operations
functional/   # FP utilities
math/         # Math operations
time/         # Time utilities
types/        # TypeScript types
```

## Usage

Browse the source and copy functions directly into your project. Functions are small and documented, the behavior should be clear.
